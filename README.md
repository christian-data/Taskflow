# TaskFlow — Gestor de Tarefas

Aplicação web desenvolvida com **React e Vite**, que permite organizar tarefas de forma simples, intuitiva e eficiente.

## Funcionalidades

- Adicionar tarefas através do botão ou da tecla Enter.
- Marcar tarefas como concluídas ou pendentes.
- Editar e guardar tarefas.
- Cancelar a edição sem perder o texto original.
- Eliminar tarefas com confirmação.
- Filtrar tarefas: Todas, Pendentes e Concluídas.
- Visualizar contadores automáticos de tarefas.
- Guardar tarefas no localStorage do navegador.
- Apresentar uma mensagem quando não existem tarefas no filtro selecionado.
- Interface responsiva para computadores e dispositivos móveis.

## Tecnologias utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Git e GitHub

## Como executar o projeto

É necessário ter o Node.js e o npm instalados.

1. Clonar o repositório.
2. Abrir a pasta do projeto.
3. Instalar as dependências:

   `npm install`

4. Iniciar o servidor de desenvolvimento:

   `npm run dev`

5. Abrir o endereço apresentado pelo Vite no navegador.

## Objetivo do projeto

O TaskFlow foi desenvolvido como projeto prático de aprendizagem de React, com o objetivo de consolidar conhecimentos em componentes, estados, eventos, renderização condicional, manipulação de arrays e persistência de dados.
